It is a C program to calculate Cell count and Seeding density across various Assay plate settings(6-Well, 12-Well,48-Well and 96-Well Assay plates)
and Trypan Blue volume ratios. In addition, the users could also customize thier own assay plate setting. This program could be fine-tuned for other 
special purposes.This program is designed to be compatably displayed in Android OS. Termux Compiler and Clang modules are the necessary requirements . For any queries, do contact the author at babumkubct@gmail.com
